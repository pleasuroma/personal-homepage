# MBTI 견종 매칭

MBTI 4문항과 생활 조건 7문항으로, 국내 인기 견종 100종 중 크기별로 피해야 할 견종 3마리와 잘 맞는 견종 3마리를 보여주는 웹앱이에요.

## 휴대폰에 앱처럼 설치하기
- **안드로이드(크롬)**: 페이지를 열고 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**
- **아이폰(사파리)**: 페이지를 열고 공유 버튼 → **홈 화면에 추가**

설치하면 주소창 없이 전체 화면으로 열리고, 한 번 연 뒤에는 오프라인에서도 열려요.

## 파일
- `index.html` 앱 전체(데이터·화면·점수 계산)
- `manifest.webmanifest`, `sw.js`, 아이콘 PNG: 홈 화면 설치와 오프라인 실행용
